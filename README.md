# 🌍 Galileo Lens

A modern web application that provides real-time Earth and climate data visualization using Next.js and shadcn/ui.

## Features

- 🌡️ Weather data based on user location
- 📍 Geolocation support
- 🎨 Modern UI with shadcn/ui components
- 📱 Responsive design

## Resources

- [Next.js](https://nextjs.org/) - React framework
- [shadcn/ui](https://ui.shadcn.com/) - UI component library
- [TypeScript](https://www.typescriptlang.org/) - Type safety
- [Open-Meteo API](https://open-meteo.com/) - Weather data
- [Lucide Icons](https://lucide.dev/) - Icons

## Getting Started

### Prerequisites

- Node.js 18+ or Bun
- npm or Bun

### Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/galileo-lens.git
cd galileo-lens
```

2. Install dependencies:

```bash
npm install
```

```bash
bun install
```

3. Start the development server:

```bash
npm run dev
```

or

```bash
bun dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
